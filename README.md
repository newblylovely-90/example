# 황은유의 서가

사서교사이자 라이브러리 게임 개발자, 두 아이의 엄마 **황은유**의 소개 페이지입니다.

정적 사이트 한 장으로 되어 있고 빌드 과정이 없습니다. `index.html`을 열면 그대로 동작합니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 페이지 전체 (마크업 · 스타일 · 스크립트 한 파일) |
| `img/twins.jpg` | 히어로 사진 |
| `img/*.jpg` | 캐러셀 6장과 경력 섹션 배경 |

## 배포

Vercel에 저장소를 연결하면 됩니다. 프레임워크 프리셋은 **Other**, 빌드 명령과 출력 디렉터리는 비워 둡니다.

## 사진 출처

히어로 사진을 제외한 이미지는 [Unsplash](https://unsplash.com) 무료 이미지입니다.
